# CodeAlpha Java Gradle Application

## Project Overview

This project is developed as part of the CodeAlpha DevOps Internship. It is a simple Java application built using Gradle.

## Technologies Used

* Java
* Gradle
* Git and GitHub
* Visual Studio Code

## Features

* Displays a welcome message.
* Demonstrates a basic Java application.
* Uses Gradle to build and run the application.

## How to Run

On Windows, open the project folder in VS Code terminal and run:

```powershell
.\gradlew.bat run
```

## Expected Output

```text
==================================
  CodeAlpha Java Gradle Project
==================================
Welcome to CodeAlpha DevOps Internship!
Application is running successfully!
```
